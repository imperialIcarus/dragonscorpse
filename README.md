# Dragon&#39;s Corpse

## Description

Dragon's Corpse is a vanilla-friendly open-source mod that adds more rewards from the dragon fight.

## Features

Dragon's Corpse adds four new drops from the dragon.

- Dragon Flesh (3-5 per dragon)
- Dragon Bone (3-5 per dragon)
- Dragon Membrane (50% chance per dragon)
- Dragon Eye (10% chance per dragon)

Dragon Flesh and Dragon Bone can be crafted into Dragonite Ingots. Dragonite Ingots can be used to upgrade Netherite armor and tools with a Dragonite Upgrade Smithing Template, which is rarely found in end cities.

The Dragon Membrane can be used to craft the Dragon Elytra.

The Dragon Eye can be used to craft the Dragon Mace and the Dragon Staff.

(See Modrinth or Curseforge page for full recipes)
